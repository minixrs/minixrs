# Slice 6.5 — TTY RX: PL011 receive interrupt + `CDEV_READ` + a VFS that does not block — Implementation Plan

**Goal:** a byte arriving on the PL011 reaches `read(0)`, and a process waiting for one does not
stop VFS serving everybody else.

**Spec:** [`../specs/2026-11-23-tty-rx-design.md`](../specs/2026-11-23-tty-rx-design.md), decisions
`R1…R12`, under the phase decisions `H1…H12` of
[`../../plans/phase-6-virtio.md`](../../plans/phase-6-virtio.md). Where this plan and the spec
disagree, **the spec wins** and the plan gets corrected.

## Global Constraints

- **Branch `feature/6.5-tty-rx`.** Every commit `--signoff`ed and GPG-signed; never `--no-gpg-sign`,
  never `--no-verify`. **No push, no PR, no CI trigger.**
- **SPDX header** first in every new `.rs` file.
- **No ABI value moves** (D8, R10). `gen-c-headers` output is diffed against `main`.
- **No kernel change** unless Task 0 or a later task finds one is needed (R9); a finding goes in the
  ledger before the code. No `#[cfg(test)]` under `kernel/src/`.
- **No polling** (I12): TTY blocks in `receive` between interrupts; VFS never spins on `EAGAIN`.
- **No new `unsafe`** outside `drivers/tty/src/pl011.rs`.
- **Overflow-safe arithmetic** in the ring's index math and the park table's sequence numbers.
- **Boots.** `$S` is the session scratch directory. Build first (`MINIXRS_SDK=/nonexistent cargo
  build -p minixrs-kernel --target aarch64-unknown-none --release`), then `MINIXRS_SDK=/nonexistent
  MINIXRS_ROOT=<disk|ramdisk> timeout 600 cargo run -p minixrs-kernel --target aarch64-unknown-none
  --release < <(tools/feed-console.sh $S/<name>.log) > $S/<name>.log 2>&1`. One boot at a time.
  Iterate and mutation-test stub-free (`--no-default-features`), judging by the specific marker.
  Read `check-boot-log.sh`'s whole output; apply the starved-boot check before believing a missing
  marker.
- **Mutation discipline** per
  [`testing-and-markers.md`](../../conventions/testing-and-markers.md#mutation-testing).
- **Counts in markers come from constants**, never typed into a driver.
- **Markdown** wraps at 100; `~/.dprint/bin/dprint fmt` + `check` and `python3
  tools/check-md-links.py` on anything edited.

## Marker text (fixed here)

```text
[diag tty] irq ok rounds=2                 (unchanged)
[diag tty] rx on                           RX masks set after the proof's last round
[diag tty] rx overflow                     forbidden; once per boot
[diag tty] rx FAIL storm                   forbidden; once per boot
[diag tty] rx FAIL enable rc=<rc>          forbidden
[diag vfs] cons.park                       first park of the boot
[diag vfs] cons.beside ok                  first file VFS_READ completed while a read is parked
init: stdin ok n=15
init: stdin FAIL n=<n> first=<byte in hex> forbidden (substring `stdin FAIL`)
```

`15` is `CONSOLE_PROBE.len()`; the string is `minix.rs stdin\n` and lives in one place the feeder
can be checked against (a host test in init compares the constant with the bytes
`tools/feed-console.sh` holds).

## Review Focus

1. **Peek-then-consume** — a failed `SYS_SAFECOPY` consumes nothing. Host test on the ring's
   `peek`/`consume` split; mutation 7.
2. **Ring wrap** — push/peek across the wrap point, full drops the newest, `len` never exceeds
   `TTY_INPUT_MAX`. Host tests with the ring pre-advanced to the last index.
3. **`CDEV_READ` length rules** — `len == 0` before the empty check (answers `0`, not `EAGAIN`);
   negative `len`; bad minor; clamp to `min(len, buffered, CDEV_MAX_IO)`. Host tests in `cdev.rs`.
4. **Park table** — one entry per slot; oldest-first by sequence; `free` on exit; an entry whose
   stored endpoint differs from the slot's current occupant is not retried. Host tests in `park.rs`;
   mutation 8.
5. **No reply to a notification** — VFS's `NOTIFY` arm sits before the request dispatch and does not
   fall into `reply()`. Mutation 4.
6. **No lost wakeup** — TTY records the waiter before replying `EAGAIN`; VFS parks before its next
   `RECEIVE`; the waiter is notified after `IRQ_ENABLE`. By reading, plus mutation 3.
7. **Acknowledge-then-drain** (R4) — the order in `irq.rs`, and that `IRQ_ENABLE` follows the drain.
   Mutations 5 and 6.
8. **The walk stops at the first `EAGAIN`** and replies to every reader served before it; a count or
   an error both free the entry.
9. **`fs.deny`'s count** is recomputed from its table after `read-console` goes.
10. **The feeder** writes exactly once, only after `cons.beside ok`, and cannot keep a finished
    boot's pipeline alive.

## Tasks

### Task 0: Measure first (R11)

Throwaway probe code in TTY, never committed. Results in the ledger.

### Task 1: the input ring and the read validation (R1, R3)

**Files:** `drivers/tty/src/input.rs` (new), `drivers/tty/src/cdev.rs`, `drivers/tty/src/main.rs`
(the `mod` line only).

- `Ring`: `push` (drops the newest when full, returns whether it stored), `peek(&mut [u8]) ->
  usize`, `consume(n)`, `len`, `dropped`. `TTY_INPUT_MAX = 256`.
- `cdev::validate_read(req) -> Result<usize, i32>`: `validate_write`'s rules for a read.
- `cdev::read_len(want, buffered) -> usize`.

**Proves it:** `cargo test -p minixrs-tty` (Review Focus 1–3).

### Task 2: VFS parks and retries (R2)

**Files:** `servers/vfs/src/park.rs` (new), `servers/vfs/src/main.rs`.

- `park.rs`: the table (`NR_PROCS` entries keyed by proc slot), `park`, `free`, `oldest`,
  `any_parked`; host tests (Review Focus 4).
- `main.rs`: the loop handles a `NOTIFY_MESSAGE` from the console driver before dispatch, with no
  reply; `do_read` returns a "parked" outcome the loop does not reply to; the retry walk;
  `do_pm_exit` frees the entry; `cons.park` and `cons.beside ok`.
- Inert at boot until Task 3: nothing answers `EAGAIN` yet.

**Proves it:** `cargo test -p minixrs-vfs`; a stub-free boot's markers unmoved.

### Task 3: TTY receives (R1, R4, R5) and init stops probing `read-console` (R7)

**Files:** `drivers/tty/src/{pl011,irq,main}.rs`, `userland/init/src/main.rs`,
`kernel-shared/src/callnr.rs` (doc comment), `tests/qemu-boot.expected`,
`tests/qemu-boot.forbidden`.

- `pl011.rs`: `getc() -> Option<u8>`, `set_rx_masks`, `ack_rx`.
- `irq.rs`: the proof hands over to the RX service; `irq FAIL extra` deleted; the storm guard.
- `main.rs`: the `CDEV_READ` arm, the waiter, `EIO` with no line.
- init: the `read-console` probe deleted, `fs.deny`'s count recomputed. Same commit, because the
  probe would otherwise park init forever.

**Proves it:** stub-free boot: `rx on` present, `irq ok rounds=2` present, every prior marker
present, `irq FAIL` absent.

### Task 4: the proof child and the feeder (R7, R8)

**Files:** `userland/init/src/main.rs`, `tools/feed-console.sh` (new), marker files.

**Proves it:** a fed stub-free boot prints `cons.park`, `cons.beside ok`, `init: stdin ok n=15`, in
that order; an unfed one prints the first two and not the third.

### Task 5: CI (R8)

**Files:** `.github/workflows/ci.yml`. The disk and ramdisk boots are fed; the reboot is not.
`shellcheck` on the feeder if the lint job covers `tools/`.

### Task 6: recorded boots (spec §3)

Both full musl-flavour boots fed, `check-boot-log.sh` for each, `diff-backends.sh`, the reboot, the
budget measurement (R11.4), the header diff.

### Task 7: mutations (spec §3)

The eight rows, each observed and reverted from a scratchpad snapshot.

### Task 8: documentation, trackers, the whole-branch sweep (spec §4)

Book, conventions, the 6.1 spec's I12 paragraph, phase file, `docs/plan.md`, the stale-claim grep,
the fresh whole-branch review.
